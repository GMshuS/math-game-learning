### 小学英语核心语法知识点清单
#### 阶段说明
- 入门低段（一年级起点1-3年级 / 三年级起点3-4年级）：以句型渗透为主，不刻意讲解语法术语，重在感知用法、形成语感
- 进阶高段（一年级起点4-6年级 / 三年级起点5-6年级）：显性讲解规则，为小升初核心考察内容

---

#### 一、入门低段核心语法（感知运用为主）
1. **名词**
   - 可数名词基础单复数：规则变化（直接加-s），少量高频不规则变化（如 `child-children` `man-men`）
   - 专有名词首字母大写规则（人名、地名、月份、节日）
2. **代词**
   - 人称代词主格：`I / you / he / she / it / we / they`
   - 基础形容词性物主代词：`my / your / his / her / its`
   - 指示代词：`this / that / these / those`
3. **动词与时态**
   - be动词 `am / is / are` 的基本搭配，以及肯定、否定、疑问形式转换
   - 一般现在时基础：实义动词原形与第三人称单数的基础用法
   - 现在进行时入门：`be + 动词-ing` 表正在进行的动作
4. **介词**
   - 基础方位/时间介词：`in / on / at / under / behind / near` 等具象场景介词
5. **句子类型**
   - 陈述句的肯定与否定形式
   - be动词、情态动词引导的一般疑问句问答
   - 基础特殊疑问句：`what / who / where / how many / how old` 引导的问句

---

#### 二、进阶高段核心语法（小升初核心考点）
##### （一）词法类
1. **名词**
   - 可数名词与不可数名词区分，不可数名词的量词搭配（如 `a cup of tea`）
   - 名词单复数完整规则：规则变化（s/es/变y为i加es等）+ 常见不规则变化
   - 名词所有格：`'s` 所有格、`of` 所有格基础用法
2. **代词**
   - 人称代词：主格、宾格的区分与句中位置
   - 物主代词：形容词性物主代词、名词性物主代词的区分与转换
   - 疑问代词：`what / which / who / whose` 基础用法
   - 不定代词：`some / any / many / much / a little / a few` 的基本区分
3. **冠词**
   - 不定冠词 `a / an` 的用法区分（按元音音素判断，非元音字母）
   - 定冠词 `the` 基础用法（特指、独一无二事物、乐器前等）
   - 零冠词基础场景（三餐、球类运动、月份星期、学科前等）
4. **介词**
   - 时间介词：`in / on / at / for / after / before` 的用法区分
   - 方位介词：`between / among / beside / opposite` 等拓展用法
   - 方式介词：`by / with / in` 表方式的基础用法
   - 高频固定介词搭配（动词短语、形容词短语）
5. **形容词与副词**
   - 形容词作定语、表语的基本用法
   - 副词的基本功能（修饰动词、形容词）
   - 三级变化：原级、比较级、最高级（规则变化+常见不规则变化，如 `good-better-best`）
   - 基础比较句型：`as...as` 原级比较、比较级+`than`、最高级+范围
6. **动词基础**
   - 情态动词：`can / could / may / must / should` 的基本用法与否定形式
   - 实义动词三单、过去式、现在分词的变化规则

##### （二）时态类（小学语法核心重点）
共四大基础时态，均要求掌握**构成、句式转换、标志词、核心用法**：
1. **一般现在时**
   - 用法：表习惯常态、客观真理、固定属性
   - 标志词：`often / usually / every day / always`
   - 难点：第三人称单数的动词变化规则
2. **现在进行时**
   - 用法：表此刻/现阶段正在进行的动作
   - 标志词：`now / look / listen / at the moment`
   - 构成：`be (am/is/are) + 动词-ing`
3. **一般将来时**
   - 用法：表将要发生的动作或计划
   - 标志词：`tomorrow / next week / in the future`
   - 两种基础结构：`will + 动词原形` / `be going to + 动词原形`
4. **一般过去时**
   - 用法：表过去某个时间发生的动作
   - 标志词：`yesterday / last week / just now / ...ago`
   - 难点：动词过去式规则变化 + 核心不规则动词（约40个高频词）

##### （三）句法类
1. **句子种类**
   - 陈述句：肯定句、否定句的转换规则
   - 疑问句：一般疑问句、特殊疑问句、选择疑问句基础
   - 祈使句：肯定/否定形式，表请求、命令、建议
   - 感叹句：`what` 与 `how` 引导的基础句型区分
2. **核心特殊句型**
   - `There be` 句型：单复数变化、就近原则、与 `have/has` 的用法区分
   - 主谓一致基础规则
3. **从句入门（仅基础感知，不深入拆解）**
   - 宾语从句入门：`I think... / I know...` 引导的简单从句
   - 状语从句入门：`because` 表原因、`when` 表时间、`if` 表条件的简单用法
