# 🧮 数学乐园扩展 — 详细设计与实施计划

## 概述

基于当前系统状态和讨论结论，本计划覆盖四大变化：

| 项目 | 决策 | 目标 |
|------|------|------|
| ① 挑战中心改名 | → **数学乐园** | 与英语乐园对称，明确学科属性 |
| ② 商店+收银合并 | → **超市大挑战** | 消除重叠，形成难度阶梯 |
| ③ 卡牌迁移 | → **跨学科卡牌世界** | 数学/英语均可产出卡牌 |
| ④ 知识点填补 | → **分批扩展题型和游戏** | 从~20%覆盖提升到~80%+ |

## 1.2 题型模块模板

所有新模块遵循现有注册模式：

```javascript
// src/questions/numberCompare.js  — 示例
import { register } from './registry';
import { randomInt } from './_helpers';

function generateNumberCompare(grade, range) {
  const { min, max } = range;
  
  let a, b, question, answer;
  
  if (grade <= 2) {
    // 低年级：20/100以内比较
    a = randomInt(min, Math.min(max, 100));
    b = randomInt(min, Math.min(max, 100));
  } else if (grade <= 4) {
    // 中年级：万以内比较
    a = randomInt(min, Math.min(max, 9999));
    b = randomInt(min, Math.min(max, 9999));
  } else {
    // 高年级：大数/小数/分数比较
    if (Math.random() > 0.5) {
      // 小数比较
      a = Math.round(randomInt(min, 100) + Math.random() * 100) / 100;
      b = Math.round(randomInt(min, 100) + Math.random() * 100) / 100;
    } else {
      // 大数比较
      a = randomInt(10000, 999999);
      b = randomInt(10000, 999999);
    }
  }

  const operators = ['>', '<', '='];
  if (a > b) answer = '>';
  else if (a < b) answer = '<';
  else answer = '=';

  question = `比较大小：${a} __ ${b}`;

  return {
    question,
    answer,
    type: 'numberCompare',
    operands: [a, b],
    inputType: 'choice',  // 选择题，选项为 > < =
    choices: ['>', '<', '=']
  };
}

register('numberCompare', generateNumberCompare);
export default generateNumberCompare;
```

## 3.3 Phaser 场景复用模式

所有几何游戏复用同一个 `GeometryScene.js`，通过参数配置切换模式：

```javascript
// src/scenes/GeometryScene.js 设计
class GeometryScene extends Phaser.Scene {
  constructor() {
    super({ key: 'GeometryScene' });
  }

  init(data) {
    this.mode = data.mode;    
    // 'identify'    — 图形识别
    // 'angles'      — 角的世界
    // 'triangle'    — 三角形探秘
    // 'area'        — 面积挑战
    // 'transform'   — 图形运动
    // 'views'       — 三视图
  }

  create() {
    switch (this.mode) {
      case 'identify':  this.createIdentifyMode(); break;
      case 'angles':    this.createAnglesMode(); break;
      case 'triangle':  this.createTriangleMode(); break;
      case 'area':      this.createAreaMode(); break;
      // ...
    }
  }
}
```
