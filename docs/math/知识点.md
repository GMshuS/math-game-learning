# 小学数学1-6年级分阶段知识清单（含运算、方程、应用题）
整体按「数与代数、图形与几何、统计与概率、应用题」四大模块划分，运算、方程、应用题随年级逐步进阶。

### 一年级
**数与代数**
- 数的认识：20以内、100以内数的读写与大小比较，数位（个位、十位），基数与序数
- 运算：20以内进退位加减法、100以内两位数加减一位数/整十数；连加连减、加减混合运算
- 常见量：钟表整时/半时认读，人民币（元、角、分）单位换算
- 规律：简单图形、数列的周期规律

**图形与几何**
- 认识立体图形（长方体、正方体、圆柱、球）与平面图形（长方形、正方形、三角形、圆）
- 位置认知：上下、前后、左右

**统计与概率**
- 简单分类整理，象形统计图与单式统计表

**应用题**
- 一步加减法应用题（求和、求差、比多比少问题）
- 连加连减、加减混合两步基础应用题

### 二年级
**数与代数**
- 数的认识：万以内数的读写与大小比较，近似数，估算入门
- 运算：表内乘法、表内除法（乘除法意义、乘法口诀）；有余数的除法；万以内整数加减；两级混合运算、小括号入门
- 常见量：长度单位（厘米、米），质量单位（克、千克），时间单位（时、分、秒）换算
- 逻辑：简单图形推理、数字推理

**图形与几何**
- 角的初步认识（直角、锐角、钝角）
- 图形运动：平移、旋转、轴对称图形初步
- 观察物体：从不同方向辨认立体图形

**统计与概率**
- 简单数据收集与整理，单式统计表进阶

**应用题**
- 乘除法一步应用题（平均分、倍数入门）
- 乘加乘减、四则混合两步应用题
- 有余数除法的实际应用问题

### 三年级
**数与代数**
- 数的认识：分数初步认识（几分之一、几分之几），一位小数的初步认识
- 运算：多位数乘一位数、除数是一位数的除法；两位数乘两位数；整数四则混合运算（含小括号）；简单分数、小数加减法
- 常见量：年、月、日，24时计时法；面积单位（平方米、平方分米、平方厘米）换算

**图形与几何**
- 长方形、正方形的周长与面积计算
- 四边形分类，平行四边形初步认知
- 位置与方向：东、南、西、北等八个方位

**统计与概率**
- 复式统计表

**应用题**
- 归一问题、归总问题
- 周长、面积实际应用问题
- 连乘、连除、乘除两步综合应用题
- 分数、小数一步加减应用题

### 四年级
**数与代数**
- 数的认识：大数的认识（亿以内、亿以上），数位顺序表，十进制计数法，自然数概念
- 运算：三位数乘两位数、除数是两位数的除法；四则运算顺序与0的运算；五大运算定律（加法交换/结合律、乘法交换/结合/分配律）与简便运算；小数的意义与性质、小数加减法
- 规律：积的变化规律、商的变化规律
- 常见量：长度、面积、质量、时间的高低级单位互化

**图形与几何**
- 线与角：直线、射线、线段；角的度量与分类（平角、周角），用量角器画角
- 平行与垂直；平行四边形、梯形的特征与高
- 三角形：分类、内角和、三边关系
- 观察物体（三视图），图形的平移

**统计与概率**
- 单式、复式条形统计图
- 平均数的意义与计算

**应用题**
- 常见数量关系：价格问题（单价×数量=总价）、行程问题（速度×时间=路程）入门
- 简便运算相关的实际应用题
- 三角形角度、边长计算，平行四边形周长相关应用题

### 五年级
**数与代数**
- 数的认识：因数与倍数（奇数、偶数、质数、合数，公因数/公倍数、最大公因数/最小公倍数）；分数的意义与性质（通分、约分、分数与除法、分数小数互化）；负数初步认识
- 运算：小数乘法、小数除法；异分母分数加减法；简便运算拓展
- 方程：用字母表示数，等式的性质，解简易方程（一步、两步）

**图形与几何**
- 多边形面积：平行四边形、三角形、梯形的面积公式，组合图形面积计算
- 长方体、正方体：棱长总和、表面积、体积、容积计算，体积单位换算
- 位置：用数对表示位置

**统计与概率**
- 单式、复式折线统计图
- 可能性：判断事件发生的确定性与不确定性，比较可能性大小

**应用题**
- 小数乘除、分数加减实际应用题
- 列方程解应用题（和差倍、行程、工程入门等）
- 长方体、正方体表面积与体积实际应用题
- 因数倍数应用（分组、铺砖、周期问题等）
- 植树问题专项

### 六年级
**数与代数**
- 数的认识：负数的完整认知，整数、小数、分数、百分数的知识体系总复习
- 运算：分数乘法、分数除法；百分数计算；比和比例（比的性质、比例的性质、正比例、反比例、比例尺）
- 方程：稍复杂的整数/分数方程，比例方程
- 思维拓展：鸽巢原理（抽屉原理）、鸡兔同笼问题

**图形与几何**
- 圆：周长、面积计算，扇形初步认知
- 圆柱、圆锥：表面积、体积计算
- 图形的放大与缩小
- 带角度的方位与位置描述

**统计与概率**
- 扇形统计图
- 可能性大小的简单计算

**应用题**
- 分数乘除应用题（含工程问题）
- 百分数应用题（折扣、税率、利率、浓度入门）
- 比例应用题（比例尺、正反比例、按比分配）
- 圆柱、圆锥表面积与体积实际应用题
- 多知识点综合应用题
